# HospitalDataAnalysis

## Description
A mini-project for analyzing hospital patient data using Python.

## Tools
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset
The `data/patients.csv` file contains patient information, including age, sex, blood pressure, cholesterol, and diagnosis.

## How to run
1. Install the required libraries:
   `pip install -r requirements.txt`
2. Open `notebooks/patients_analysis.ipynb`.
3. Run the notebook cells.
